# W4Program
This C++ program evaluates a player’s weekly performance based on training and sleep hours. It calculates the readiness score, determines the player’s level (Beginner, Intermediate, or Pro), and provides advice.
The menu includes three options:


Evaluate Level — displays the player’s level and saves a report to report.txt


Build Training Plan — creates a 3-session weekly training plan


Readiness & Recovery — assesses fatigue risk and recommends rest days


The program validates all user inputs and saves results to report.txt.
Created as a Week 4 assignment to practice conditions, loops, and file handling in C++.
